# 🎛️ Erland Faturrahman — Technical PM Portfolio (3D Industrial Edition)

> **Associate Product Manager | Technical Product Management**  
> An Awwwards-inspired, 3D interactive hardware showcase portfolio built with a **Scandinavian Industrial / Teenage Engineering TP-7 & Pixel Rise** design aesthetic.

---

## 🌟 Key Features

- **💻 3D Hardware Canvas**: Real-time floating MacBook & monolith stone scene with responsive mouse parallax physics (Three.js & React Three Fiber).
- **🎛️ Scandinavian / Teenage Engineering Aesthetic**: Matte off-white canvas, high-contrast typography (Space Grotesk + Space Mono), and signature electric orange accents (`#FF5A00`).
- **📊 Interactive PRD & RICE Prioritization Engine**: Real-time scoring simulator calculating `(Reach × Impact × Confidence) ÷ Effort` with dynamic P0/P1/P2 classification, live User Stories, and Acceptance Criteria.
- **📂 Live GitHub Projects & Sandbox Showcase**: Direct interactive integration with live deployed apps on GitHub Pages (`VoidShare`, `Esco E-Procurement`, `Speech Translator Enterprise`, `Nusantara Trading Terminal`).
- **🎵 Auto-ON Generative Ambient Soundscape**: Offline analog synth pad chord progression (`Em9 → Cmaj7 → Gmaj7 → Dadd9`) synthesized with the Web Audio API and top-bar animated equalizer.
- **🎯 Precision Industrial Reticle Cursor**: Dual-layer crosshair cursor with magnetic hover snapping and micro-status labels.
- **📐 Full-Width Fluid Dashboard Layout**: Panoramic responsive layout spanning edge-to-edge across all viewports.

---

## 🛠️ Tech Stack

- **Core & Framework**: React 19, Vite
- **3D Graphics & Physics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Styling & Design System**: Tailwind CSS v4, Custom CSS Tokens, Google Fonts (Space Grotesk, Space Mono, Plus Jakarta Sans)
- **Audio Engine**: Web Audio API (Generative Analog Synthesizer)
- **Icons & Effects**: `lucide-react`, `canvas-confetti`

## 🚀 Getting Started Locally

```bash
# Clone repository
git clone https://github.com/Erlandfatur/portofolio-erland.f.git

# Navigate to directory
cd portofolio-erland.f

# Install dependencies
npm install

# Start local development server
npm run dev
```
